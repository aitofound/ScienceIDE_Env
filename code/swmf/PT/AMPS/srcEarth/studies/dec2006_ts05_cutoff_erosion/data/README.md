# Data included with the December 2006 cutoff study

The package contains the processed observations actually consumed by the
model--data comparison.  It does not disguise a fitted empirical boundary as an
observation.

## PAMELA

`observations/pamela_table_s1.csv` is a complete transcription of Supporting
Information Table S1 from Adriani et al. (2016), DOI
`10.1002/2016SW001364`.  It contains 37 orbit midpoints, seven rigidity bins,
published asymmetric uncertainties, and the original single missing cell.
Dates are midpoints of approximately 94-minute intervals.  The AMPS comparison
therefore uses an orbit-scale 475-km shell operator; it does not claim to
reconstruct unavailable event-level PAMELA look directions or attitude.

## NOAA POES/MetOp

`observations/poes_metop_meped_boundaries.csv.gz` contains the 3,904-cell
`C10_POES_T50_V3` reference derived from NOAA/NCEI historical SEM-2 Level-2
16-second data for NOAA-15, NOAA-16, NOAA-17, NOAA-18, and MetOp-A.  P6/P7 are
the primary comparison.  P8/P9 are retained as diagnostics because their broad
response and subcommutated sampling make a sharp lower-threshold rigidity
interpretation less secure.

The raw daily NOAA files are not duplicated in this compact package.  They are
public and can be downloaded and processed reproducibly with:

```bash
python3 vendor/C10/download_poes_sem2.py \
  --start 2006-12-05 --end 2006-12-16 \
  --satellites n15,n16,n17,n18,m02 --format txt \
  --output-dir data/raw/poes_sem2

python3 vendor/C10/build_poes_reference.py \
  --input-dir data/raw/poes_sem2 \
  --output data/observations/poes_metop_meped_boundaries_rebuilt.csv.gz
```

The downloader writes original URLs, sizes, and SHA-256 digests.  See
`vendor/C10/README.md` for all quality and boundary-extraction controls.

## TS05 driver

`drivers/ts05_dec2006_5min.txt` contains 865 five-minute records from
14 December 00:00 UT through 17 December 00:00 UT.  The columns are GSM IMF,
solar-wind velocity and density, temperature, SYM-H, quality flags, dipole tilt,
dynamic pressure, and TS05 `W1`--`W6`.  The fixed digest is recorded in
`provenance.json`.  No extrapolation beyond the supplied interval is allowed.

This driver is not a measured three-dimensional magnetic-field map. The IMF,
solar-wind plasma, and SYM-H fields originate in observation products, whereas
dynamic pressure, dipole tilt, and `W1`--`W6` are calculated inputs to the
empirical TS05 field. An audit on 2026-09-08 against the NASA five-minute OMNI table
found exact stored-precision agreement for IMF, velocity, density, temperature,
and SYM-H at all 826 epochs where current OMNI supplies valid plasma/IMF data.
The other 39 epochs coincide with OMNI gaps and use the driver's alternate
quality status. See the top-level README for the intervals and interpretation.

The legacy bundled header does not contain the official source archive digest.
For a publication archive, preserve the source URL, archive SHA-256, member
name, and preparation time generated by
`vendor/C9/tools/prepare_official_ts05_driver.py`.

## Interpretation of the frozen observation products

The PAMELA CSV is a transcription of a published, orbit-averaged cutoff product;
it is not an event list. The POES/MetOp table is reproducibly derived from
NOAA/NCEI 16-second Level-2 observations using the documented background-
normalized isotonic T50 algorithm; it is not raw detector telemetry. A fresh
C10 archive rebuild reproduced every one of its 3,904 cell keys and differed in
only two AACGM values by `0.00001 deg`. Publication packages must retain the
NOAA download/reference manifests, pass-level crossing table, source hashes,
and AACGM software version in addition to the compressed reference checksum.

## Integrity

Run `python3 scripts/validate_package.py`.  It checks every frozen digest,
schema, row count, cadence, temporal coverage, and required AMPS input keyword.
