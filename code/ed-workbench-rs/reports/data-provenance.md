# Scientific Data Provenance Register

Date: 2026-07-30

This register identifies where every main numerical claim in the workbench
comes from and what it is allowed to validate. It is the entry point for team
review; detailed values and commands remain in the linked artifacts and
reports.

## Source classes

Every number belongs to one of four source classes:

1. **Published value** — transcribed from a named table at only the precision
   printed by the paper.
2. **Independent oracle** — generated with pinned PySCF from an explicitly
   recorded geometry, basis, electron treatment, and convergence policy.
3. **Rust result** — computed by this repository from a checksum-identified
   FCIDUMP or by the direct `libcint` path.
4. **Performance observation** — measured on a named machine or Slurm job;
   it is not a chemistry reference.

These classes must not be conflated. In particular, extra Rust or PySCF digits
must not be attributed to a six-decimal literature table.

## Machine-readable artifact map

### PySCF-generated references

- `fixtures/*/reference.json` contains molecular input, units, PySCF version,
  convergence state, energies, and FCIDUMP checksum where applicable.
- `fixtures/*/ao_reference.json` contains independent overlap, AO-core,
  electron-repulsion, orbital, and transformed-integral data.
- `fixtures/h2o-dzp-fc/generation_metadata.json` explicitly records that
  PySCF FCI was skipped by a size guard.
- `fixtures/h2o-ccpvdz-ae/pyscf-crosscheck.json` contains the independent
  same-input method hierarchy through CCSD(T).

### Literature transcriptions

- `fixtures/h2o-631g-fc/hirata2000-table2.json` contains the six-decimal
  equilibrium CC, CI, and MBPT differences from the paper.
- `fixtures/h2o-dz-ae/published-fci-anchor.json` and
  `fixtures/h2o-dzp-fc/published-fci-anchor.json` contain only the printed
  Kállay FCI anchors and their source DOIs.

### Rust calculations

- `fixtures/h2o-631g-fc/cc_series_results.json` and
  `level3_series_results.json` contain the primary CC/CI/MBPT series.
- `fixtures/h2o-dz-ae/davidson_result.json` and
  `fixtures/h2o-dzp-fc/davidson_result.json` contain extended Rust FCI runs.
- `fixtures/h2o-ccpvdz-ae/fci-c2v-xh5-result.json` contains the new full
  Slurm provenance, checksums, cross-checks, and acceptance flags.

### Performance data

- `fixtures/h2o-631g-fc/parallel-sigma-m4.json` is a five-process Apple M4
  serial/parallel sigma measurement.
- `fixtures/h2o-ccpvdz-ae/benchmark-m4.json` and
  `benchmark-m4-summary.json` are bounded Apple M4 cc-pVDZ kernel
  measurements, not full-FCI timings.
- `fixtures/h2o-ccpvdz-ae/xh5/production-23008083.*` are unedited Slurm logs.
  Slurm step `MaxRSS`, not `/usr/bin/time` around the `srun` launcher, is the
  authoritative remote-process memory observation.
- `fixtures/hpc/scnet-2026-07-30.json` records the checksum-pinned v0.4.0
  SCNet build gate, 18 robustness cases, 216 repeated solves, Slurm
  accounting, and the distinction between 1,008 requested and 560 observed
  allocated CPUs.

## Interpretation rules

- Compare total energies only when geometry, basis, electron treatment,
  charge, spin, symmetry sector, and nuclear repulsion are the same.
- A point-group block is an exact representation only for the corresponding
  irrep; it is not evidence for a different spin or symmetry sector.
- `FCI` means exact diagonalization only within the recorded finite orbital
  basis and Hamiltonian.
- CCSD(T) is used as an independent scale check for the cc-pVDZ result, not as
  a variational bound.
- Wall times and memory are hardware- and configuration-specific.
- Printed literature precision determines the maximum claimed literature
  agreement.

## Why this provenance matters

The repository intentionally mixes implementation tests, independent
high-precision oracles, published rounded anchors, and performance records.
This register prevents a plausible-looking number from being compared to the
wrong Hamiltonian. It also makes each headline claim reviewable without
requiring Python, access to the supercomputer, or trust in a presentation.
