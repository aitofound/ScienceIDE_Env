# Level 2 Arbitrary-Order CC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement determinant-based arbitrary-order CC(n) with denominator updates and DIIS.

**Architecture:** Cluster amplitudes live on reference-connected determinants through rank `n`. A generic cluster operator and its Taylor exponential reuse the determinant basis and Hamiltonian operator from Level 1.

**Tech Stack:** Rust 2024, nalgebra; PySCF CCSD and published tables as oracles.

## Global Constraints

- `n` is runtime-configurable and not hard-wired to doubles.
- CC(2) means full CCSD.
- Residual norm and energy convergence are both reported.
- Full-rank CC must reproduce tiny-system FCI.
