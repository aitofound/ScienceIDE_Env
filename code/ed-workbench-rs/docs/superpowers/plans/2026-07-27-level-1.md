# Level 1 Direct FCI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement alpha/beta string direct FCI and Davidson, culminating in the frozen-core H2O/6-31G target.

**Architecture:** Lexical string link tables drive a matrix-free Hamiltonian operator. Davidson consumes an operator trait and a separately computed Hamiltonian diagonal; Level 0 dense matrices remain independent regression oracles.

**Tech Stack:** Rust 2024, nalgebra, serde; PySCF 2.14.0 offline fixtures.

## Global Constraints

- Never store the full H2O/6-31G Hamiltonian.
- Direct sigma must match dense `H*C` within `1e-11` on H2/H4 random vectors.
- Davidson must report both energy change and residual norm.
- Primary target uses H2O/6-31G canonical RHF orbitals with oxygen 1s frozen.
