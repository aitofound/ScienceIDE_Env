# Level 3 Workbench Methods Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add executable and verified CI(n), MBPT(n), and unitary CC(n).

**Architecture:** CI uses projected Hamiltonian spaces, MBPT uses a diagonal Fock partition and order recursion, and UCC uses the anti-Hermitian cluster operator with variational optimization.

**Tech Stack:** Rust 2024, shared operator core, nalgebra.

## Global Constraints

- All three method families must produce numerical results and tests.
- CI(full rank) and variational UCC(full rank) are bounded by the FCI result.
- MBPT reports every correction rather than only the final sum.
