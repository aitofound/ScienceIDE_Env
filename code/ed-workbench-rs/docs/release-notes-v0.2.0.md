# v0.2.0 — General active spaces and checked numerical contracts

v0.2.0 is the first post-submission hardening release. It preserves the
validated v0.1.1 Hamiltonians, algorithms, and headline energies while making
the reusable library boundary safer.

## What changed

### General active-space selection

`ActiveSpaceSpec` can remove both explicitly doubly occupied and virtual
orbitals:

```rust
let result = build_active_space(
    &problem,
    &ActiveSpaceSpec {
        frozen_occupied: vec![0],
        frozen_virtual: vec![11],
    },
)?;
```

The result carries `active_to_original` and `original_to_active` maps. Lists
are checked for duplicates, overlap, range errors, impossible electron counts,
and removal of every orbital. The established `freeze_core` function remains
available as a compatibility wrapper.

### Checked combinadic addressing

Occupation-string counts, ranks, and inverse ranks now use checked `u128`
arithmetic:

- exhaustive small-space tests preserve the existing numeric lexical order;
- `C(64,32) = 1,832,624,140,942,590,534` is handled exactly;
- invalid strings and ranks return typed errors;
- occupation strings are generated by unranking instead of scanning all
  `2^n` bit patterns;
- allocation boundaries reject counts that do not fit the platform.

### Coupled-cluster diagnostics

CC configuration now rejects non-finite or non-positive tolerances and empty
iteration/DIIS limits before iteration. Iterations guard energy, residual, and
amplitude state against non-finite values. Results report an explicit
`converged` or `maximum_iterations` termination reason.

`cc-series` accepts `--json-output` and writes a schema-versioned record
containing solver configuration, every rank, energy, residual, termination,
timing, and optional published comparison.

## Numerical compatibility

This release intentionally does not change:

- the FCIDUMP convention;
- the direct-FCI Hamiltonian;
- Davidson equations or defaults;
- ranked subset convolution;
- CC residual equations, warm starts, or DIIS;
- any committed reference value.

The H2O/6-31G frozen-core acceptance remains:

| Quantity | Value |
|---|---:|
| determinants | 245,025 |
| FCI | `-76.121174204141980 E_h` |
| CC(2) | `-76.119629519205702 E_h` |
| CC(8) | `-76.121174196144139 E_h` |
| Hirata 2000 CC entries | 8/8 matched |

## Verification

```bash
scripts/verify-submission.sh

cargo run --release --locked -- cc-series \
  fixtures/h4-sto3g/FCIDUMP \
  fixtures/h4-sto3g/reference.json \
  --max-rank 2 \
  --residual-tolerance 1e-8 \
  --json-output /tmp/h4-cc-series.json
```

Coordinates remain Angstrom at the public molecule boundary and are converted
to Bohr for libcint. Energies and energy-valued integrals remain Hartree.

## Scope

v0.2.0 does not yet add a disk-backed Davidson workspace or a parallel
direct-FCI sigma policy. Those are isolated into the v0.3 and v0.4 follow-up
releases so this generality layer can be audited independently.
