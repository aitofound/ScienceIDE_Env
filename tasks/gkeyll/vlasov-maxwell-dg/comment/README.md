# vlasov-maxwell-dg: authoring notes

This directory is hidden at Harbor runtime and is not part of the solver contract. `comment/pipeline/` contains CLI-written module, survey, self-validation, and runtime records.

## Module

This leaf owns Gkeyll's production continuum kinetic implementation under `vlasov/`: Vlasov-Poisson/Vlasov-Maxwell DG transport, kinetic species, moments, collisions, and field coupling. Eight official checks cover Landau damping, two-stream instability, a two-species electrostatic shock, BGK relaxation, electromagnetic advection, an electron-ion sheath, and both classical and special-relativistic Weibel dynamics. Gyrokinetic and PKPM implementations are deliberately assigned to their own approved modules. Scope of the survey and the checks, settled at review on 2026-09-04: the `rt_vlasov_*` regressions of `vlasov/creg/` (52 C drivers, all with a verdict in `comment/pipeline/test-survey.json`) and their four Lua mirrors. The other 67 C drivers in that directory, the Vlasov-Poisson app family (`rt_vp_*`), the canonical Poisson-bracket family (`rt_can_pb_*`) and the DG scalar, fluid and Maxwell drivers (`rt_dg_*`, `rt_diffusion_*`), and the 124 Lua inputs under `vlasov/luareg/`, are built by the same application but are outside this leaf's check set.

## Tolerances

All checks grade full binary64 dynamic-vector histories while ignoring adaptive-step timestamps. Each variant moves one physical input by two binary64 ULP. Every check also declares the skill-5.8.0 alternative build, `run.sh altbuild`: the nominal inputs on the same pinned source compiled strict-IEEE with the same gcc (-O2, no -ffast-math, -ffp-contract=off, no -march=native; the oracle image carries that library tree as `build-ieee/` next to the default -O3 -ffast-math -march=native `build/`). Self-validation grades the altbuild run against nominal with each check's own validator and writes the distance into `evidence.floor` and `evidence.altbuild` of the rubric: the floor between two legitimate builds, measured by the CLI rather than typed. The bounds were finalized with the curator at review on 2026-09-04 (PR #418): two-stream at 2e-5 (an earlier round), Weibel raised from 1e-11 to 1e-10, the rest kept at 1e-11.

## Blind spots

The suite is serial CPU and does not separately test MPI decomposition, CUDA execution, every basis/order combination, standalone electromagnetic-wave propagation, all collision models, or full cell-distribution files. Integrated histories can miss compensating local errors, though the L2 and field-energy histories complement the conserved moments. In the two-stream check, `alpha=1e-6` makes the early linear-growth field energy smaller than `atol`; those values are judged mostly by the absolute term, while the later nonlinear history provides stronger discrimination. The two Weibel checks grade integrated moments, L2 and field energy rather than mode-resolved growth rates, and the sheath parallel-momentum history uses its documented component-specific bound. The altbuild is one alternative build (strict IEEE, same gcc); it does not stand for a different compiler or a GPU reduction order, which is what the margins above the measured floors are for. Build note: run.sh copies the source tree with `cp -a`; with `cp -R` the copied objects are older than the copied sources and make rebuilds the whole Vlasov library per check (43 minutes on one core, seen on the x86 worker on 2026-09-05), whereas the oracle image's two prebuilt trees are meant to be relinked only.
