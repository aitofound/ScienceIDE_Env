## Build

Each check is self-contained. run.py fingerprints source, build files, flags and compiler identity, locks a container-local cache, builds an unchanged scratch copy with make, and reports SAB_BUILD_SECONDS (zero on reuse). Checks in the same container reuse this cache; separate Docker containers have separate caches. Nominal/variant use GCC -O3, altbuild uses Clang -O3; no fast-math or source patch. Both images install identical build-essential, clang, Python/numpy and CA packages from the pinned Debian base. Each check requests one CPU and 1 GiB; the Mac VM has two CPUs and 4 GiB, with one check container at a time via SAB_SOLVE_CPUS=1. The contributor approved installation and execution with “同意，按此计划运行”. The formal ARM64 Docker calibration completed on 2026-09-17T04:28:06Z using Debian 12, GCC 12.2 and Clang 14.0.6. The two task images have a combined reported size of approximately 0.54 GB. The stock A100 descriptor is a downstream template, not a claim that validation ran on a GPU.

## Tolerances

The contributor Weixuan Liao approved the numerical bounds on 2026-09-17 (“认可这些规则，继续本机复验”), with the cross-architecture evidence gap explicitly retained. Positions are decoded into WGS84 ECEF and each component is bounded by 0.05 m. Six signed root-covariance outputs, or NMEA orthometric height/geoid separation, use 0.05 m. Time bounds are one printed unit (0.001 s or NMEA 0.01 s), except the precision check allows 1e-8 s. Epoch masks, fix status and used-satellite counts must agree exactly. Validator distance is the dimensionless maximum of field error/bound, not a mixed-unit or true-position error; per-field metre/second errors are also retained. The formal container selfcheck measured the variant on all seven checks: the largest ECEF component change was 1.572–1.713 mm; the NMEA height component changed by 2 mm. The maximum normalised bound fraction was 0.04, giving 25× headroom against this variant. This is not a portability guarantee. The alternative compiler produced identical graded values in all seven checks, so the measured zero floor is uninformative at the printed precision; it must not be interpreted as zero platform uncertainty. Native preflight is development evidence only. Output rounding and the pinned 1e-4 least-squares stopping criterion motivate the scale but do not alone justify it. Diagnostic-only differences must never be called physical movement.

## Blind spots

The official nominal data have 120 input epochs and 115 accepted fixes. A trace-only native audit linked the five final rejected epochs to GDOP > 30. The validator compares the whole accepted/rejected mask rather than silently selecting 115 rows. The RINEX header position is approximate, not an independent geodetic truth; its vertical discrepancy is not a tolerance. Ionosphere/troposphere defaults are off after initialisation. No Doppler, multi-constellation, RAIM stress or explicit clock-bias output is exercised. The dataset is too short to establish a useful speedup. More representative configurations, independent truth and workload scale are scientific review items for the steward/PI. No source behaviour has been changed to hide these limitations.
