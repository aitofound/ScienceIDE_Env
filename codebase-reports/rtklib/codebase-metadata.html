Pitfalls of running the codebase

  • native build: Upstream ANSI C flags hide strtok_r on macOS; upstream Linux link flags include unavailable librt. → Add -D_DARWIN_C_SOURCE and override LDLIBS=-lm for this Mac only; preserve original source and upstream makefiles.
  • test/utest/makefile: make all fails on missing src/stec.c and missing input_rtcm3 linkage. → Record failure. For t_ppp, an explicit source list supplies real RTCM dependencies without changing the production implementation; other targets remain unverified.
  • rnx2rtkp-test01: No average base-station position; zero exit code, zero solution rows. → Mark this attempted run as unsuccessful. Future checks need explicit output-count validation and a documented valid input configuration.
  • unit-time: Future leap-second expectation predates source-table updates. → Document stale reference and derive the expected value from the pinned leap-second table; no source or assertion changed in this investigation.
  • convbin-test01: A 2009 fixture generates 2029 dates using the current host clock. → Investigate an explicit reference epoch before adopting receiver-conversion checks; not yet resolved.
  • convbin-test03: Garbage output paths and file-open failure with partial output filename options. → Document the uninitialized filename mechanism. A complete explicit output-path configuration needs separate verification; no production patch made.
  • convbin-test11: Official Javad example cannot derive time for its output filename. → Record failed example; time/input reconstruction needs additional investigation.

Not run

  • RTKRCV, STR2STR live-server examples: Require receiver/network streams, an interactive service, or replay files absent from this tree. No external connection or service was started.
  • End-to-end PPP: The tested official RNX2RTKP configurations cover single/relative positioning. No matching complete official PPP observation/precise-product case was established; t_ppp is only supporting-function coverage.
  • Remaining receiver-conversion examples: Four representative native attempts already expose time and filename issues. Full conversion coverage is deferred until the user selects the task scope.
  • t_preceph, t_gloeph, t_tle: Official builds failed RTCM linkage; not yet rerun with corrected linking. No runtime pass claimed.
  • t_geoid: Requires several external geoid datasets at paths outside the repository. The executable was built, but the full test was not run.
  • t_stec, t_corrperf, t_filter: Respectively missing production stec.c; incomplete correlator source and missing SDR dependency; a debug helper with invalid stdout.h include and no main.
  • Utility example families and manual worked examples: Make targets were inventoried; several refer to absent external fixtures. Full run/coverage selection remains pending. This is an initial landscape, not a completed official-test survey.
